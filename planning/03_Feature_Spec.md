# 03 시스템 기획 — 읽고 바로 구현할 규칙
## 자동 영업·강화
전체 코인/분 = sum(판매가×60/주기초×레벨×단계배수)×(1+직원 판매보너스 합).
주기 기본30초. 단계배수 레벨1~9 ×1,10~24 ×2,25~49 ×4,50~100 ×8.
기본 강화비=ceil(레벨1 기본 분당수익×4). 다음 비용=ceil(기본비×1.12^(현재레벨−1)).
1/10/MAX는 단계별 올림 후 합산. 소수 코인 잔여분 보존. 모든 메뉴 합산, 수요·재고 분배 없음.
보너스0% 기본2메뉴는 44코인/분, 25분 무강화/무연구는 1,100코인. 직원5%면 46.2코인/분.
머신·손님 애니메이션 종료로 돈을 다시 주지 않는다. 프레임률·미니 모드로 수익이 줄지 않는다.
오프라인 기본상한24h·100%, 음수시간0. 연구 완료/예약 시작/직원 교체 경계를 나눠 계산.
기존 20메뉴의 8.5시간 결과는 이번 8메뉴에 적용하지 않는다. 새 구성으로 simulation을 재실행한다.

## 연구·해금
진행1·대기3. 사용자가 예약한 순서대로 조건+코인이 충족되면 자동 시작. 앞이 막히면 뒤를 건너뛰지 않음.
시작할 때 비용1회. 대기 취소/순서변경 가능, 시작 후 취소 불가(기본값). 연구 부족해도 판매는 지속.
재료 연구는 영구 완료 플래그. 머신과 재료 조건 모두 AND. 메뉴 자동 Lv1 해금, 개방비/숙련 없음.
판매 강화는 연구슬롯을 쓰지 않으며 코인 즉시 결제. 연구 속도 변경 때 이전 구간 먼저 정산.

## 직원과 손님
직원 후보3, 무료 직원1, 최대3, 고용/교체 2000코인. 후보는 창 열기/재시작으로 재추첨 안 됨.
채용 후 해당 후보만 보충. 의상·헤어·색상과 판매/연구 보너스는 독립 추첨. 보너스 각각 정수0~10%.
교체 전 수익/연구를 정산. 임금·피로·승급·등급·서사 없음. 동일 스탯은 동일 경제 결과.
손님은 이동/이용 연출이며 고유ID 수집·도감·특수 보상 없음. 외형 조합은 seed와 파츠ID로 재현.

## 배치·타일
윗면32×16/공간32×32, 두께4는 시각 표현만이다. 탁자·의자는 배치 기준점에서 위로8px 한 번만 보정한다.
줌2배에서는 표시 차이가16화면px가 되지만 논리 높이와 셀은 그대로다. -4를 더하거나 보정을 두 번 하지 않는다.
받침/인물 부착은 명시된 시각 앵커를 따르되 같은 보정을 중복 적용하지 않는다.
가구 이동/4방향 회전/보관·그리드 스냅. 탁자에는 유효하게 사용하는 의자 최소1개 필요.
문은 벽의 허용 슬롯에 배치. 문 앞 및 서비스/좌석 사용지점까지 경로 없으면 적용 금지.
머신은 호환 카운터/선반 슬롯에만 배치. 받침 이동·회전·보관 시 머신도 같이 처리.
서비스/계산 앵커는 유효 후보에서 자동 선택. 계산대를 세밀하게 최적화하지 않음.
동선은 유효성/연출 목적. 경로 길이/좌석 밀집으로 돈이 늘지 않음.
현재 영업배치와 편집초안 분리. 편집 중 임시 미완성 허용, 적용 때만 검사/원자결제/저장.
1×1 클릭·드래그·사각영역·4방향 연결채우기·스포이트·기본복원. 한 획=Undo1회.
바닥 스타일 해금 뒤 칠할 때 반복비용 없음. 소유량·동선·잔액은 적용 시 재검사.

## 작업 도구·UI·창작
메모 자동저장·한글, 할 일 추가/완료/정렬, 타이머25/5+사용자지정+일시정지.
메모 입력 중 게임 단축키 금지. 종료/절전은 집중 기록 미적립. 카페 정산과 분리.
로컬 음악/권리확인 음악·환경음만. Spotify/YouTube OAuth 직접연동은 이번 범위 아님.
UI는 고정 스크린샷이 아니라 실제 버튼/스크롤/툴팁/입력상태. 문자는 이미지에 굽지 않음.
로컬 창작은 PNG 가져오기→역할/기준점/방향→미리보기→검사→저장→적용.
공개 프리셋은 배치/외형 참조만. 코인·연구·직원스탯·메모·경로·인증 포함 금지.
미소유/미지원 가구는 안내, 구독/가져오기로 경제 해금 우회 금지. 누락외형은 보유 기본외형으로.
도전과제는 판매100/연구1/타일편집1을 자동 기록. 경제 보상·진행 게이트 없음.
