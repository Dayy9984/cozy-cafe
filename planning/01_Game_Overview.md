# 01 Game Overview — 기획자용
## 사용자 확정
작은 꾸미기 공간·작업 도구가 베이스이며 카페가 자동으로 성장한다. 업무 중 조작은 거의 없다.
플랫폼 Mac/Windows. 원작을 빌드 수정하는 것이 아니라 그 공간 경험을 참고해 새 카페를 구현한다.
머신은 그라인더·에스프레소 머신·스팀기·얼음제빙기·믹서기만 존재한다.
재료는 연구로 영구 해금. 구매·재고·소모·재입고·원가 없음. 손님은 프리셋/색상 조합.
직원은 프리셋/색상/스탯 랜덤. 도감·단골·호감도·의뢰·직원 서사·별도 목표 시스템 없음.
가구/1×1 타일/프리셋/Undo/Redo/동선/문/의자/머신 받침, 창작용 편집기 포함.
아트: 2.5D 아이소, 윗면 64×31px · 공간 기준 64×62px · 시각 두께 4px(물리 높이 0) · 탁자/의자 표시 보정 (0, -8px). 적은 공통 인물 파츠를 재사용. UI/UX도 제작 범위.

## MVP 기본값 — 사용자가 승인한 출시 수치 아님
카페1 / 머신5 / 메뉴8 / 연구5 / 일반가구12 / 바닥6. 8×8 논리 격자, 단층.
그라인더+에스프레소 기본 보유, 나머지는 연구. 모든 해금 메뉴가 독립 자동 수익을 더한다.
머신 영구 보유가 해금 조건이며 보관 중에도 판매. 복제 개수로 수익 증가 없음.
직원 무료1·최대3·판매/연구 스탯 각0~10%. 타이핑/타이머/음악은 기본 수익과 분리.
코인→연구/판매레벨→추가메뉴/수익. 쉬는 시간에는 꾸미기/채용. 기초 영업은 소모품 없이 지속.

## 사용자 시나리오
1. 기본 머신·직원으로 시작, 에스프레소/아메리카노 자동 판매.
2. 카운터/탁자·의자를 놓고 바닥 한 칸 변경, 저장.
3. 얼음제빙기·우유·스팀기 연구 예약 후 미니 모드.
4. 한글 메모/할 일/타이머 사용 여부와 상관없이 판매·예약 연구 진행.
5. 복귀해 새 메뉴와 수익 확인, 1/10/MAX 강화 또는 가구 구매.
6. 종료 후 복귀 정산, 같은 인물·배치·메모·연구 상태 유지.

## 후속으로 분리, 삭제하지 않는 것
Steam 게시/구독, 온라인 갤러리, 외부 음악 계정 연동, 실제 지역 날씨, 지점/상인/룬.
첫 창작 기능은 로컬 PNG/타일/외형/프리셋 제작·적용. 프로토타입 생략과 최종 기능 삭제를 구분한다.
